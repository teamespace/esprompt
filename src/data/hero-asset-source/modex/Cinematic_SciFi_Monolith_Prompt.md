# Cinematic Sci-Fi Monolith Landscape Prompt

## Objective

Create an ultra-cinematic science fiction landscape featuring a colossal
alien monolith standing alone on a barren extraterrestrial world. The
atmosphere should evoke mystery, awe, isolation, and cosmic scale.
