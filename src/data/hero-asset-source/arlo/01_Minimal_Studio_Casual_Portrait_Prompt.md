# Minimal Studio Casual Portrait Prompt

## Objective

Recreate the reference image with nearly identical framing, negative
space, lighting, and premium minimalist fashion aesthetic.

## Prompt

``` text
Ultra-realistic luxury menswear editorial photographed in a seamless light warm-gray cyclorama studio.

Aspect ratio: 16:9.

A single young male model stands centered with a large amount of negative space surrounding him. Curly medium-length hair, dark sunglasses, relaxed expression, hands inside pockets. Wearing an oversized cream overshirt left open over a white heavyweight t-shirt, loose black wide-leg trousers and off-white minimalist sneakers.

Soft diffused daylight-style studio lighting with almost invisible shadows. Camera at eye level using approximately an 85mm full-frame lens. Neutral warm-gray backdrop with subtle paper sweep. Minimalist composition emphasizing scale and whitespace.

Luxury fashion campaign, ultra sharp, photorealistic, 8K, natural skin tones, clean styling, no props, no text, premium lookbook photography.
```

## Match Instructions

``` text
Match the camera distance, subject scale, amount of empty space, lighting softness, wardrobe silhouette, pose, backdrop tone, and centered composition. Avoid reproducing identifiable brand logos.
```
